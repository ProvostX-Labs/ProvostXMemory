    Namespace ProvostXMemory.Graph

    Classes

    ExtractionResult

    Entity + relation extraction result.

    GraphCluster

    A graph cluster (community) with an optional summary record id.

    GraphEntity

    An extracted graph entity. EntityId is the stable slug id; Name is the canonical display form; Aliases holds alternative spellings/casings; RecordIds lists the records mentioning it.

    GraphRelation

    A relation between two graph entities, treated as undirected for traversal. Weight is implicit: RecordIds.Count equals the number of supporting records.

    GraphRetriever

    Graph-backed retriever: lowercased query tokens are matched against entity ids and entity names/aliases (via SearchEntitiesAsync(string, int, CancellationToken)) and against record tags from the scope's snapshot; matched entities seed a multi-source neighbor walk up to MaxHops hops via NeighborsAsync(string, int, CancellationToken); records touched by discovered entities and their relations plus SummaryRecordId of matched clusters are scored by hop distance (direct evidence = 1.0, each additional hop × 0.5 decay; independent evidence sums). Entity/relation extraction is an index-time concern (IEntityExtractor); this retriever is deliberately query-time token-based.

    HeuristicEntityExtractor

    Zero-dependency heuristic extractor: capitalized multi-word phrases and keyword/tag matches become entities; entities co-occurring inside one record become relations (label "co-occurs", weight = number of supporting records). Deliberately simple default; hosts inject stronger IEntityExtractor implementations.

    JsonlMemoryGraphStore

    JSONL-backed graph store: graph/entities.jsonl, graph/relations.jsonl and graph/clusters.jsonl per scope directory (via GraphPath(string, string, string)). Paths resolve only through the layout, so cross-scope access stays structurally impossible. Every mutation rewrites the affected JSONL file transactionally via AtomicFileWriter.

    Interfaces

    IEntityExtractor

    Host-injected entity/relation extractor (LLM or heuristic).

    IGraphRetriever

    Retrieves records from a relevant subgraph plus cluster summaries.

    IMemoryGraphStore

    Graph-backed store over memory records: entities, relations, paths, clusters.

    IMemoryGraphStoreResolver

    Resolves the scope-pinned graph store for a memory scope. Implementations must guarantee that the returned store is bound to exactly the requested scope, so cross-scope access stays structurally impossible.
