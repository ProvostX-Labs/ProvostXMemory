    Class GraphRetriever

    Graph-backed retriever: lowercased query tokens are matched against entity ids and entity names/aliases (via SearchEntitiesAsync(string, int, CancellationToken)) and against record tags from the scope's snapshot; matched entities seed a multi-source neighbor walk up to MaxHops hops via NeighborsAsync(string, int, CancellationToken); records touched by discovered entities and their relations plus SummaryRecordId of matched clusters are scored by hop distance (direct evidence = 1.0, each additional hop × 0.5 decay; independent evidence sums). Entity/relation extraction is an index-time concern (IEntityExtractor); this retriever is deliberately query-time token-based.
