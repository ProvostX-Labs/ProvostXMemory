    Class Bm25Scorer

    BM25-lite scoring: saturated term frequency (k1 = 1.2) × IDF plus a key-match boost (default 2.0) on key-term hits and a modest single-term category match bonus (0.5). Classic BM25-lite: no length normalization, no third-party dependencies. Stateless pure scoring — corpus statistics are passed in per call (the index owns them).
