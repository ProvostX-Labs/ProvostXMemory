    Class DeterministicEvalCorpus

    Seeded synthetic corpus: N records per scope across M scopes, round-robin assigned to keyword clusters (exact balance) so every scope/cluster pair yields the same number of expected matches per query. Content is a seeded shuffle of the record's cluster terms plus filler words, one hard-negative term from a seeded foreign cluster, and one seeded noise token — derivable relevance without an LLM: the expected matches for a cluster query are exactly that cluster's records. Identical seeds yield byte-identical corpora, verified via DeterminismHash().
