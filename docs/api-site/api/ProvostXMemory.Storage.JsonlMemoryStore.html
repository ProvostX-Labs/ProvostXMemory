    Class JsonlMemoryStore

    Default JSONL-backed store: one append/rewrite-friendly records.jsonl per scope, one JSON document per line, transactional rewrite on every mutation. All operations take the scope as a required parameter and resolve paths only through MemoryRootLayout, so cross-scope access is structurally impossible.
