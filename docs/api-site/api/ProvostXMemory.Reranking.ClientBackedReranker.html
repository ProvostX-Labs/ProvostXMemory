    Class ClientBackedReranker

    Adapter wrapping the host-injected IRerankerClient: the client returns best-first ids; this adapter maps ids back to candidates, keeps provenance of the wrapped (fused) scores, and handles unlisted candidates per ClientBackedRerankerOptions. The client itself stays host-owned infrastructure.
