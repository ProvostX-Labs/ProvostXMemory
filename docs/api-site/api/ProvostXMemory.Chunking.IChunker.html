    Interface IChunker

    Splits a record's content into embedded units for the dense index. Chunks carry exact offsets back into the original content, so a chunk hit resolves to its parent record — the whole record is always what surfaces in results, never the fragment.

    Implementations: StructuredChunker cuts on markdown structure first (headings, paragraphs, then sentences) and only hard-slices oversized content; SizeChunker packs by size with optional overlap — fixed-stride windows in geometry mode, shared whole words in separator mode. Both preserve every character of content across the split (mod whitespace at cut points).

    Chunk ids are scope-qualified (kind|scope-id|record-id|index) — see ChunkIdCodec; ids containing the '|' separator are rejected at compose time.
