    Namespace ProvostXMemory.Consolidation

    Classes

    ClusterSummarizer

    Builds a summary MemoryRecord from a near-duplicate cluster: the concatenated member keys plus deterministic representative excerpts, category "summary", and Meta carrying the cluster-summary flag, member count, cluster id and member ids. Cluster id = sha256 over ordinal member ids, so the same cluster always maps to the same summary id (idempotent re-consolidation).

    ConsolidationReport

    Outcome counters of one consolidation pass over a scope.

    ConsolidationReportMeta

    Side channel that attaches the pass ConsolidationReport to the records returned by IMemoryConsolidator: the interface signature is fixed by the scaffold, so the report travels as a "consolidation-report" Meta entry on each returned record (returned copies only — store contents are never touched by this). Pure helpers over immutable records; the serializer options are immutable after creation.

    ConsolidationTuning

    Consolidation pass tuning knobs, layered over ConsolidationOptions (thresholds have defaults and stay host-overridable via the base record).

    MemoryConsolidator

    One consolidation pass over a scope, executed against the scope-bound IMemoryStore: (1) TTL expiry deletes records whose ExpiresAt is in the past, (2) near-duplicate detection via IDedupDetector keeps the oldest record of each duplicate group and unions the tags of the removed duplicates into the kept record, (3) remaining records are clustered by embedding similarity and clusters of sufficient size are emitted as summary records via IClusterSummarizer, (4) all mutations are counted in a ConsolidationReport attached to the returned records. Survivors and summaries are returned (survivors first, summaries last); an empty scope is a no-op returning an empty list. Every deletion goes through the store's scope-bound API — cross-scope access stays structurally impossible.

    ThresholdDedupDetector

    Near-duplicate detection: cosine over records embedded via the injected IVectorEmbedder, falling back to lexical Jaccard over token sets when both vectors degenerate (zero norm). A pair counts as duplicate when its similarity is greater than or equal to the given threshold. Arguments are ordered deterministically (earlier-id first) before evaluation, so the result never depends on call-site order; evaluation itself is pure. This type holds no mutable state.
