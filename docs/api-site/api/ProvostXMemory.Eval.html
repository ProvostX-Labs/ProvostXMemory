    ClusterHashEmbedder

    Deterministic fake embedder for eval runs — NOT a real model. Cluster-preserving: every token maps to a fixed slot from a stable FNV-1a hash; each of a record's tokens adds a fixed cluster id + token hash signature so similar content (shared cluster terms) lands near the same direction, with per-record seeded noise amplitude only. No randomness at embed time: same text → same vector, always.

    DeterministicEvalCorpus

    Seeded synthetic corpus: N records per scope across M scopes, round-robin assigned to keyword clusters (exact balance) so every scope/cluster pair yields the same number of expected matches per query. Content is a seeded shuffle of the record's cluster terms plus filler words, one hard-negative term from a seeded foreign cluster, and one seeded noise token — derivable relevance without an LLM: the expected matches for a cluster query are exactly that cluster's records. Identical seeds yield byte-identical corpora, verified via DeterminismHash().

    EvalCase

    One golden retrieval case: a query bound to a scope plus the record ids a good retriever should surface. Relevance is binary (1.0) unless graded weights are given. The query's TopK is overridden by the eval runner options' TopK at run time.

    EvalCaseMetrics

    Metrics for one eval case: Recall@k, Precision@k, MRR and NDCG@k over the ranked result ids judged against the case's golden relevance.

    EvalCaseSet

    A named set of golden eval cases grouped under one logical set id. Case ids must be unique within a scope (cross-scope ids may repeat); the set is immutable after creation.

    EvalCaseTrace

    Per-case ranked outcome: returned ids with their graded relevance gains and how many returned records came from a scope other than the case's own (isolation guard).

    EvalCaseTraceHit

    One returned id with its graded relevance gain for this case.

    EvalMetricBreakdownEntry

    Metric means for a breakdown group (scope or retriever stage).

    EvalMetricMath

    The metric formulas, implemented independently of any search engine and unit-tested against hand-computed values:
    • Recall@k = |relevant ∩ top-k| / |relevant| (0 when no relevant ids).
    • Precision@k = |relevant ∩ top-k| / k (unfilled top-k counts against precision).
    • MRR = 1 / rank of the first relevant hit, else 0.
    • NDCG@k = DCG@k / IDCG@k with DCG = Σ relᵢ / log₂(rank + 1), rank starting at 1.
    All instance methods (no static state shared across instances).

    EvalMetricThresholds

    Minimum metric values for the aggregate EvalReport. A violation is any actual value strictly below its threshold. All thresholds optional (null = unchecked).

    EvalMetrics

    Aggregate over all cases: plain means of the per-case metric values.

    EvalReport

    Serializable result of running an EvalCaseSet: per-case metrics, the aggregate, per-scope and per-stage breakdowns, threshold violations, and the per-case ranked id lists (with graded gains) for diffing. JSON-ready via System.Text.Json.

    EvalReportJson

    JSON (de)serialization for EvalReport (System.Text.Json).
