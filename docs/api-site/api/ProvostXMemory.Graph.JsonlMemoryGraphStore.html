    Class JsonlMemoryGraphStore

    JSONL-backed graph store: graph/entities.jsonl, graph/relations.jsonl and graph/clusters.jsonl per scope directory (via GraphPath(string, string, string)). Paths resolve only through the layout, so cross-scope access stays structurally impossible. Every mutation rewrites the affected JSONL file transactionally via AtomicFileWriter.
