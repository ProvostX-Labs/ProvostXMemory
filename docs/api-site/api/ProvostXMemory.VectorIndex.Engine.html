    EngineVectorIndexFactory

    Own-engine factory: Flat → FlatExactIndex, Ivf → IvfFlatIndex, Hnsw → HnswIndex.

    EngineVectorIndexFactory.Options

    Backend options for every created index.

    FlatExactIndex

    Own-engine exact backend: SIMD brute-force scan (Vector512→256→128, scalar fallback) over the in-memory float[] store. Fully built in memory; Flush is a no-op.

    FlatExactIndex.Options

    Backend options: the ranking metric (default cosine).

    HnswBeamSearcher

    Exact analog of the canonical HNSW SEARCH-LAYER routine, in score form (higher = closer): candidate heap = max-heap by score (top = nearest candidate, expanded first), result heap = min-heap by score bounded to ef (top = worst kept result = the stop gate). A candidate whose score falls below the gate stops the beam. The visited set resets per layer traversal (canonical: fresh visited per searchLayer call); the query score cache lives in HnswSearchContext and persists across layers of the same query. Returns results sorted best-first (score desc, node id asc).

    HnswBuilder

    Own HNSW construction (canonical INSERT algorithm, level-0 full beam): inserts each item in order, greedily descends from the entry point through layers above the node's top level, then beam-inserts per layer with the M / maxM neighbor pruning heuristic (keep-if-closer-than-direct-neighbors). Writes backlinks for pruned victims. Deterministic: seeded level assignment + insertion order + deterministic tie-breaks.

    HnswGraph

    Immutable-after-build layered HNSW graph topology: per-node adjacency sets per layer, plus the entry node and current max level. Pure data: ids/vectors live in VectorItemStore; the graph only stores link structure (int ids). Mutations happen only during construction — the finished graph is published in one reference swap and never modified afterwards (immutable-index semantics, ARCHITECTURE.md addendum).

    HnswIndex

    Own-engine HNSW backend with IMMUTABLE-INDEX + BATCH-REBUILD semantics (patent-avoidance design, ARCHITECTURE.md addendum 2026-10-13): the layered graph is fully rebuilt from the item store on every Build, Add, and Remove — there is deliberately NO incremental update of a live graph, the method covered by US 15/929,802 "Dynamic Updates for HNSW". Core construction + layered greedy/beam search (unpatented) is implemented from scratch. Mutations mark the published graph dirty; the next search rebuilds it once (same batch-rebuild behavior as IvfFlatIndex). Cosine metric: vectors are L2-normalized internally. Deterministic given the same items in the same order + seed.

    HnswLevelAssigner

    Deterministic level assignment for HNSW layers: each node's top level is drawn from the geometric distribution ⌊-ln(U)/ln(levelFactor)⌋ (U uniform in [0,1), factor < 1). Own SeededRandom keeps level assignment stable across .NET versions/platforms; same seed + same insertion order → identical layer structure.

    HnswOptions

    HNSW backend tuning parameters, mirroring the canonical algorithm's knobs: M outgoing links per node above layer 0 (MaxLevel0Connections on layer 0, typically 2·M), LevelFactor as the level-assignment divisor (1/ln(M) canonically), EfConstruction beam width while inserting, EfSearch beam width at query time, and the deterministic Seed for level assignment. Same seed + same insertion order → same graph.

    HnswPublishedGraph

    The published immutable snapshot of a built HNSW graph: row-order ids parallel to the normalized vector rows and the graph topology. Swapped in atomically after each full rebuild; never mutated afterwards (batch-rebuild semantics).

    HnswSearchContext

    Reusable traversal context for one built HNSW graph: row-order ids parallel to normalized vector rows, a per-query dot-product score cache (NaN = unscored; zero-vector queries legitimately score 0 and MUST be rescored), and the visited set shared by construction-time multi-layer traversals. Score cache + visited set are reset per query (ResetForNewQuery()); the query is copied into a reusable buffer so no span state is held across calls.

    HnswSearcher

    Query-time traversal over a built HNSW graph: greedy descent from the entry point through upper layers to layer 1, then a single ef-bounded beam search on layer 0, sorted best-first. Read-only over the published immutable graph.

    IvfFlatIndex

    Own-engine IVF-Flat: deterministic k-means coarse quantizer + inverted lists; search probes the nprobe nearest clusters (by quantizer metric) and scores members exactly. Mutations mark the partition stale; the next search rebuilds it (batch-rebuild semantics per the 2026-10-13 addendum). Flush is a no-op (in-memory).

    IvfFlatIndex.Options

    Backend options: metric, cluster count, probe count, k-means effort, deterministic seed.
