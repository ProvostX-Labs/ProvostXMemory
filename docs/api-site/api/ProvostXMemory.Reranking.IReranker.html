    Interface IReranker

    The post-fusion scoring stage: reranks fused candidates against the query. The default ScoreBoostReranker adds deterministic boosts (tag/key/category term matches) and penalties (extremely short or long content) without ever dropping a candidate; a NoopReranker preserves fused order. Hosts may inject an LLM- or cross-encoder-backed reranker through this interface — the library stays model-free.

    Ranks exactly once: the retrieval pipeline reranks internally; a second pass over already-reranked results compounds boosts (found by audit) — hosts calling RerankAsync(RetrievalQuery, IReadOnlyList<ScoredMemoryRecord>, CancellationToken) directly own that responsibility.
