    Class MemoryRootLayout

    Root folder + scope path resolution: <root>/<scope-kind>/<scope-id>/.... Every caller-supplied segment is validated to be a single, safe path segment (no traversal, no separators, no Windows-reserved names) and every resolved path is checked to stay inside the root folder.
