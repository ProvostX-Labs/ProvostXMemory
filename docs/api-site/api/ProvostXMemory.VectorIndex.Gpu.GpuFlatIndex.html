    Class GpuFlatIndex

    GPU-accelerated exact flat index (ILGPU kernel scan). When no GPU is available the injected CPU fallback IVectorIndex is used for every operation with identical semantics — the fallback path must pass the engine conformance suite unchanged. Kernels load lazily; all GPU faults collapse to CPU-fallback execution.
