    Class GraphIndexLedger

    Index-time graph maintenance over the scope-pinned IMemoryGraphStore (resolved via IMemoryGraphStoreResolver): per record, the wired IEntityExtractor's entities/relations are upserted for the record's scope only; when a record is forgotten, its mentions are dropped by re-extracting the scope's remaining snapshot. The ledger itself holds no per-record entity cache — graph stores accumulate weight by design, so Forget rebuilds the affected entity mention lists from the surviving records. Scope comes from the record; the resolver is scope-exact by contract.

    RecordClusterSummaryAsync(MemoryRecord, CancellationToken)

    Records one IClusterSummarizer-produced summary as a graph cluster: the summary's member record ids are resolved against the scope's snapshot, members are re-extracted (one batch, same discipline as ApplyAsync(MemoryScope, MemoryRecord, CancellationToken)) and every entity attributable to at least one member becomes a cluster member, linked to the summary record id. Entities the extractor lists without per-record attribution (empty RecordIds) count as members too — they were extracted from these very records. Unresolvable member ids are skipped (partial clusters beat dropped clusters); a record without the cluster-summary flag or cluster-id meta, or with no attributable entities, records nothing and returns null. Scope comes from the summary record itself, so the write stays scope-bound by construction.
