    Class VectorMath

    PURE STATIC UTILITY (no mutable state, thread-safe by construction; the one sanctioned static exception per architecture principles). Stateless numeric kernels for the engine: dot product via Vector512 → Vector256 → Vector128 with scalar fallback, norm, normalize, cosine. Deterministic order of accumulation for a given hardware width.
