    Namespace ProvostXMemory.Logging

    Classes

    ConsoleMemoryLogSink

    Writes log entries to standard output as plain text lines.

    FileMemoryLogSink

    Append-only file sink with per-date rolling and lazy directory creation. Each line is written with FileShare.Read and flushed immediately.

    HashChainAppender

    Computes SHA-256 entry hashes chained to the previous entry's hash and assigns monotonic sequence numbers. Pure computation is static; the instance tracks only the chain head.

    LogChainVerificationResult

    Result of verifying a hash-chained log file.

    LogChainVerifier

    Pure verifier for hash-chained JSON-lines log files. Reads a file, checks hash-chain linkage and sequence-number continuity, and reports the first broken line when the log has been tampered with.

    MemoryLogEntry

    A single memory log entry.

    MemoryLogJson

    JSON (de)serialization helpers for log lines.

    MemoryLogJsonLine

    Wire shape of a log entry line used by the file sink and the chain verifier.

    MemoryLogScope

    Scope information attached to a log entry.

    MemoryLogger

    Facade over the logging pipeline: on/off gate, level filter, hash chaining and fan-out to the configured sink. When disabled, no entry objects are allocated and no writes occur.

    RetentionSweeper

    Deletes log files older than the configured retention window.
