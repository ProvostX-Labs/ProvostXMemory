    Class ExampleRig

    Shared wiring helper for the examples: every service is composed exactly as a host would — MemoryServiceBuilder over the production JsonlMemoryStore, the deterministic ClusterHashEmbedder (no real model, no network), and the own-engine backends. All storage roots live under the temp directory; nothing personal and nothing outside the example's own root is touched.
