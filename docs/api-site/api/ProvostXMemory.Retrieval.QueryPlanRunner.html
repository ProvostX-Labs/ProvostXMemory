    Class QueryPlanRunner

    Executes a declarative QueryPlan. Each step fans out to its target scopes (target scope strings are "<scope-kind>/<scope-id>" pairs; empty targets mean the query's own scope), runs the injected retriever in every target scope with per-scope ids namespaced, and merges the step lists via the injected IResultFuser. When every step's top score is below WeakEvidenceThreshold, a single second pass runs once against the rewritten text from the injected IQueryTextRewriter; its results replace the first pass. Record resolution happens against each target scope's own snapshot — a record id from scope A never resolves into scope B.
