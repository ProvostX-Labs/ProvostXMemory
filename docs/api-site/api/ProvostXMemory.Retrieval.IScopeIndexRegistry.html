    Interface IScopeIndexRegistry

    Maps a MemoryScope to its per-scope retrieval artifacts. Implementations must be scope-exact: a lookup for scope A never returns an artifact of scope B (no parent fallthrough, no default forwarding) — cross-scope access stays structurally impossible.
