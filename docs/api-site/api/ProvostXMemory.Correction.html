    Namespace ProvostXMemory.Correction

    Classes

    CorrectionOptions

    Options for the corrective retrieval pipeline. Typed options injected by the host (no environment configuration in product code).

    CorrectiveRetriever

    Grader-gated corrective retrieval around an injected IHybridRetriever: candidates pass or are dropped per IRetrievalGrader; below-floor candidates are not yielded. One rewrite-and-retry cycle via IQueryRewriter runs when the first pass graded any candidate Uncertain or yielded nothing acceptable (all-Irrelevant/all-below-floor). When nothing survives, the optional IExternalFetcher hook (null = skip) runs once. Every stage reports diagnostics.

    CorrectiveRetriever.StageNames

    Diagnostic stage names reported in Stage.

    GradedCandidate

    A grade assigned to one candidate.

    KeywordQueryRewriter

    Deterministic, zero-dependency query rewriter: distills the query to its key terms via KeyTerms(string) — stopwords stripped (acronyms preserved), duplicates collapsed. Emits a single-space-joined term list; empty queries rewrite to the empty string.

    Interfaces

    IExternalFetcher

    Fetches content from external sources (host-injected; the library stays network-agnostic). Returning an empty list (or null) yields no fetched-stage content.

    IQueryRewriter

    Rewrites/expands a query for corrective retrieval (host-injected when an LLM-backed rewriter is desired).

    IRetrievalGrader

    Grades candidates for relevance (host-injected).
