    Class MultiRepresentationRetriever

    Multi-representation retrieval: instead of scoring whole-record content, the query is embedded once and compared against each representation's precomputed vector for the requested modality. Representation vectors are indexed in the vector index under "repr|<recordId>|<index>" ids (see RepresentationId(string, int)); hits map back to their parent record, per-record scores take the best-matching representation, and per-modality provenance is attached. Scope comes from the query; registry lookups are scope-exact.
